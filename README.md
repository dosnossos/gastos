# Gastos in Home

App de gastos domésticos (PWA) — iPhone, Android e PC.

**Site:** https://dosnossos.github.io/gastos/

## Arquivos na raiz do repositório

- `index.html` — app
- `sw.js` — offline + notificações
- `manifest.webmanifest` — instalação
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png`

## Sincronização

JSONBin configurado no `index.html` (`SYNC_BIN` / `SYNC_KEY`).

## Instalar

- **iPhone:** Safari → Compartilhar → Adicionar à Tela de Início
- **Android:** Chrome → Instalar app
- **PC:** Chrome/Edge → ícone de instalar na barra

## Notificações

- Ajustes → Ativar avisos
- Lembrete forte com app fechado: exportar **Calendário (.ics)**
